# Legalese

AI-powered legal document generator built using Python.

## About

Legalese generates rental agreements from user-provided details.

## Features

- Generate rental agreements
- User-provided rental details
- AI-powered document generation

## Project Structure

- `rental_agreement.txt` — Rental agreement template/document
